# Sistem Rekomendasi Makanan (Nutri AI) 

Sistem rekomendasi makanan berbasis AI yang membantu Anda memilih makanan berdasarkan:
- **Berat Badan**
- **Tujuan** (Diet, Bulking, Muscle Gain, Maintain)

Menggunakan model **Random Forest** dengan akurasi tinggi untuk mengklasifikasikan nutrisi makanan.

## Cara Menggunakan
1. Masukkan berat badan Anda.
2. Pilih tujuan diet Anda.
3. Klik "Dapatkan Rekomendasi".
